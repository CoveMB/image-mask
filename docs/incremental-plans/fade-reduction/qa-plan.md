## Implementation work and sensitivity

FR1 owns Q1–Q6/Q9 with source Tasks 1–4; FR2 owns Q7–Q8, the Shadow branches of Q3–Q4, and both-target Q6/Q9. Test names/files in the source are proposals to refine against current fixtures; acceptance outcomes are binding. New ordinary tests stay beside their behavior. No shared testing infrastructure, coverage quota or speculative checks are needed.

The material transitions are absent→legacy→explicit upgraded edit; enabled/OFF; clear/restore; same/changed alpha; no-op/changed amount; cold/warm validation; current/stale raw manifest; draft→submitted→edited while pending→late success/failure; and one/two independent targets. Q1–Q8 distinguish these outcomes. Omitted combinations are limited to redundant permutations after representative interaction assertions; do not omit source-required branches merely to bound test counts. No live model check is needed for an effect-only feature; existing explicit integration skips must be reported. Large-photo latency/peak memory remains unmeasured until a bounded synthetic observation; geometry limits are not performance guarantees.

For consequential sensitivity, retain valid fixtures and compare known wrong reference outputs: additive overlap, dropped/doubled reduction, multiplying alpha into q, ignoring protection on partial-alpha/nonfull-reduction samples, interpolating faded RGB and stale raw-manifest admission. Use literal or scalar expectations and causal RED where practical. Do not add a mutation framework. RED caused by setup/import failure is not behavior evidence. Never widen tolerances or weaken assertions to pass.

Public technical lookup on 2026-10-27 supports API assumptions only: [Python 3.12 duplicate-key behavior](https://docs.python.org/3.12/library/json.html#repeated-names-within-an-object), [NumPy 2.3 ties-to-even rounding](https://numpy.org/doc/2.3/reference/generated/numpy.rint.html), [SciPy EDT](https://docs.scipy.org/doc/scipy-1.17.0/reference/generated/scipy.ndimage.distance_transform_edt.html), [Pillow 13 release notes](https://pillow.readthedocs.io/en/stable/releasenotes/13.0.0.html) and [patched APNG advisory](https://github.com/python-pillow/Pillow/security/advisories/GHSA-5xm2-6676-qcp9). The versioned SciPy 1.17.1 documentation URL was unavailable; the official [1.17.1 release](https://github.com/scipy/scipy/releases/tag/v1.17.1) identifies a bug-fix release, and its [tagged source](https://raw.githubusercontent.com/scipy/scipy/v1.17.1/scipy/ndimage/_morphology.py) confirms the same EDT signature, binary input and float64 distance behavior. This establishes API correspondence, not runtime feather quality. [darktable drawn masks](https://darktable-org.github.io/dtdocs/en/darkroom/masking-and-blending/masks/drawn/) is interaction precedent only; it does not establish this project's equations, limits or photographic quality.
