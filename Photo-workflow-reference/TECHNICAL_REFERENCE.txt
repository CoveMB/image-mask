EXACT TESTED PROCESSING REFERENCE

1. Baseline RAW batch
Ten original DNGs were read, never overwritten. The stored checksums and three historical contract tests can be found in mask_test/. The original input files are not in this archive.
Python 3.12.14; rawpy 0.27.1; LibRaw 0.22.1. AHD demosaic; automatic EXIF orientation; full visible RAW raster with no additional crop and no separate application of DNG DefaultCropSize. Explicit LibRaw daylight baseline because this decoder reported invalid camera coefficients. use_camera_wb=False, use_auto_wb=False, sRGB, output_bps=16, no_auto_bright=False, auto_bright_thr=.01, bright=1, gamma=(2.4,12.92), half_size=False, median_filter_passes=0. No added sharpening/noise reduction. A 16-bit RGB TIFF retains the developed master; RGB8=round(RGB16/257) is the processing/reference PNG, with sRGB profile. This recipe is not a reproduction of phone JPEG rendering.

BiRefNet_dynamic-matting uses a reviewed local custom-code implementation, safetensors, bb_pretrained=False, CPU float32, six intra-op/two inter-op threads and seed 0. Mean(.485,.456,.406), std(.229,.224,.225). Inference aspect ratio is preserved and right/bottom padded with edge pixels to multiples of 32. Script default and early pilot were long edge 1024. The FINAL TEN-PHOTO BATCH used long edge 1536: content1157x1536 for nine images and1156x1536 for caterpillar; all inputs padded1184x1536. Padding is removed and the sigmoid mask bilinearly resized to native developed dimensions. Final outputs3072x4080 for nine images and2974x3950 for caterpillar. A native-sized export is not native-resolution inference. Alpha is quantized to16-bit; encoded-sRGB black result=round(RGB8*alpha16/65535). Final historical CPU inference+exports530.61seconds, peak6233.1MiB; these are source-environment observations, not local performance guarantees.

2. Guided subject selection and matting
SAM2.1 hiera-small proposes masks from positive/negative pixel-coordinate points and optional xyxy boxes. The saved processor uses its standard1024x1024 overview; three candidate masks are generated per selection. Human/assisted source inspection selected candidates and authored the trimap. The runner does not accept natural-language instructions or create its own trimap.
ViTMatte-small-composition-1k runs1024x1024 native-pixel crops, nominal256px overlap, stride768, with an extra last origin to cover the boundary (which can create greater overlap). No matting input downsampling. Border ramps use sin((i+.5)/overlap*pi/2)^2; weighted predictions are blended. Known background(0) forces alpha0, verified opaque foreground(255) forces alpha1, unknown(128) retains estimated alpha. Finite predictions, full weight coverage, dimensions and saved-mask round trips are checked. Alpha16 PNG is the high-precision mask; RGBA PNG has8-bit alpha. RGB is decoded8-bit for this prototype. This is not end-to-end 16-bit foreground processing.

3. Dragonfly final
Native chosen JPEG2047x2048. Four prompt groups: whole dragonfly, body, upper-right wing, lower-right wing. Candidate1 selected for all four. Binary closing8px, hole filling, body erosion25px and combined silhouette dilation30px form the reviewed second trimap. Manually specified source-visible lower-left defocused wing polygons remain UNKNOWN, not painted opaque. Two full matting passes, followed by one local1024 crop xyxy(200,0,1224,1024). Source-verified head and body-backed wing-root cores were expanded35px, merged with20px feather and opacity increases only.38,199 alpha pixels increased in this final correction. RGB remains the exact chosen decoded source. The final mask is authoritative; rerunning one whole-frame pass from a final trimap is not identical to the recorded sequence of localized merges.

4. Spider and web final
Actual RAW capture had a .jpg filename but DNG content; inspect signatures rather than extension. Native developed raster1536x2040 after orientation. Approximate metadata white balance from AsShotWhiteXY using calibration1/color matrix1 and analog balance; white multipliers[1.184668677583271,1,2.6280525030098163,1]. Threshold.0001; other saved development details in guided_mask_test/spider_raw_preparation/final_development.json. This is distinct from the baseline daylight batch. The complete metadata-conversion implementation was not recovered as a standalone script; the recipe/result is recorded, and production RAW handling remains a design task.
SAM spider-and-prey candidate1, opaque interior distance>=12px, uncertainty through25px outside silhouette. Source-visible narrow leg guides require>=5px interior. Detailed filament paths mark only UNKNOWN search corridors; they do not create foreground web pixels or RGB. Two full matting passes were used. A separate contrast-ridge extraction experiment was rejected as noisier and is not the final method or an included pipeline stage.
Repair v3 adds five source-verified background-core polygons and remattes crop(480,420,1504,1444). Blend support=clip((35-distance_outside_SAM)/15,0,1); values below.5/255 become0. Original fully opaque anatomy stays locked, then known background cores are enforced. The localized RGB cleanup estimates photographed background from known empty pixels, with dilation4px around alpha>.012 and Gaussian sigma18, then amount=.35*(1-alpha)*support; repairedRGB=clip((sourceRGB-amount*background)/(1-amount),0,1). It is a bounded heuristic inverse mixture, not physical reconstruction. Source RGB is separately retained, opaque RGB/alpha unchanged, and web outside support unchanged. Recorded175,533 changed alpha pixels and152,580 changed color pixels. Four measured gap regions went from median alpha about.10-.31 to0.

5. Independent adjustable shading
Uses the existing3072x4080 developed source and unchanged base alpha. Inward distance from alpha>=.5; smoothstep falloff width48px grasshopper or88px dahlia. Thin-structure core radius14px,8px transition and Gaussian sigma2. Direction estimate from alpha smoothed sigma12; side/lower edges weighted more than top. Highlight protection uses luminance(.2126,.7152,.0722), sigma6, start.68/range.25 and maximum75% attenuation of effect. Low-alpha protection smoothstep(alpha/.35). Zero-alpha background and interior beyond band stay unchanged. Stored SHADOW_WEIGHT_16BIT is relative intensity, not replacement alpha. Tested maximum layer opacities0%,12%,24%; current preference is adjustable and24% tentative, not fixed approval. Composite=RGB*baseAlpha*(1-opacity*shadowWeight) in encoded sRGB. A different compositing gamma can change visual strength.
A masked foreground group should apply base alpha ONCE to source plus the black shading layer. A pre-baked12%/24% RGBA overlay is used at100% layer opacity unless deliberately reducing it again. Shading cannot repair an inaccurate mask or color contamination. Web/hairs/antennae/petal tips need explicit protection; no spider shading was tested.
